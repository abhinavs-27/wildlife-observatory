# Benchmarks

Generated by `scripts/benchmark.py`. Pi 400 numbers will be added once the hardware arrives.

**Takeaways for the Pi 400 (4 GB, 4× Cortex-A72):**
- MegaDetector alone adds about **0.9 GB**. With both models resident on CPU, the process peaks
  around **2.4 GB**, which is too much next to the OS, edge and dashboard in 4 GB. So the Pi
  defaults to **detect-only** (`WORKER_KINDS=detect`, `mem_limit` 1.8 GB) and classification
  runs on the Mac.
- Detection took 0.9 s/image on 4 Mac CPU threads. Expect roughly 5–8 s/image on the Pi
  (estimate). That's fine for motion-triggered photos and still under a minute to an alert for a
  few photos.
- On the Mac's GPU (MPS), detection takes 0.12 s and classification 0.20 s per image.
